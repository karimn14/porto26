Executive Summary: Engineered an end-to-end industrial motor control and supervisory platform spanning factory-floor PLC hardware to cloud analytics. Programmed an Omron CP1E PLC with ladder logic for three-phase motor sequencing and safety interlocks, designed an operator touchscreen interface on a Weintek cMT series HMI, integrated a Node-RED edge gateway over Modbus TCP/RTU, and built a Next.js web portal logging time-series motor telemetry to MongoDB.

01Industrial Scope & Plant Architecture

Modern Industry 4.0 factories require bridging rugged operational technology (OT) on the shop floor with flexible information technology (IT) in the cloud. Motors and drives must not only be controlled with deterministic safety interlocks but also monitored continuously for predictive maintenance.

I architected and deployed a multi-tier IIoT motor control platform connecting factory-floor PLCs to a cloud-accessible supervisory dashboard with real-time analytics.

Fig 1. Figure 1: Weintek industrial touch HMI screen: motor RPM, current draw, thermal trend graphs, and manual override controls.

025-Tier Edge-to-Cloud Communication Pipeline

The system spans five integrated industrial layers:

  • Level 0/1 (Field & Control): An Omron CP1E PLC executing deterministic Ladder Logic manages motor contactors, soft-starters, emergency stop chains, and inductive speed sensors.
  • Level 2 (Local Supervisory): A Weintek cMT touch HMI communicates with the PLC via RS-485 Modbus RTU, rendering high-contrast ISA-101 screens for operator control.
  • Level 3 (Edge Gateway): A Linux edge computer running Node-RED polls Modbus TCP/RTU registers at 2 Hz, packages motor health metrics (RPM, current, temperature, running hours) into JSON payloads, and publishes them over encrypted MQTT.
  • Level 4/5 (Cloud SCADA & Database): A custom Next.js web application subscribes to MQTT topics via WebSockets, rendering live SVG telemetry widgets and persisting historical time-series records to a MongoDB database for analytics.
Fig 2. Figure 2: Next.js cloud SCADA dashboard: live telemetry charts, alarm logging, and historical motor performance analytics.

03Safety Interlocks & Modbus Mapping

Key automation and software engineering decisions:

  • Hardware & Software Fail-Safes: Implemented hardware E-stop circuits backed by software watchdog heartbeat registers. Loss of edge communication halts motor commands and locks controls in a safe idle state.
  • Comprehensive Modbus Register Map: Created structured 16-bit holding register mappings across the PLC, HMI, and Node-RED gateway, standardizing float-to-integer conversions and bitmasked alarm flags.
  • Role-Based Web Access: Built secure operator and administrator authentication in Next.js, allowing remote monitoring while restricting motor actuation commands to verified local personnel.

04Operational Reliability & Real-Time Metrics

Bench and prototype validation confirmed industrial reliability:

  • Sub-200 ms end-to-end telemetry propagation latency from PLC register change to cloud browser update.
  • Zero data loss during simulated network disconnects thanks to Node-RED local buffer queuing.
  • Intuitive UI reduced simulated operator alarm diagnosis time by over 50%.
