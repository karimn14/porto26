# porto26 — Nabil Karim Abdurrahman

Personal portfolio. Static site, no build step.

- `index.html` — main portfolio (entry point)
- `Portfolio.html` — same content (kept for internal links)
- `journal/` — learning journal channels + episodes
- `projects/` — project case studies
- `image-slot.js` — image drop component

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```

## Deploy (Vercel)
No config needed — it's a static site with `index.html` at the root.
Import the repo at vercel.com and deploy.
